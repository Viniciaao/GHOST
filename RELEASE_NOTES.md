# Black Desert → Skyrim SE/AE · Catálogo 0.1.0

> **Release documental / pré-release. Não é um modpack instalável.**
> **Nenhum arquivo de mod foi baixado ou anexado.**

Pesquisa em português para Skyrim Special Edition / Anniversary Edition **PC**, com corte em **06/09/2026**.

## Conteúdo

- **75 registros**: 49 principais, 18 a aprofundar e 8 históricos/indisponíveis.
- Packs, armaduras/roupas, refits de corpo, cabelos, animações, patches, integrações e personagens.
- Fontes por item, nível de evidência, dependências anotadas, ressalvas de runtime e permissões de reupload.
- Interface **offline** com busca, filtros e seleção pessoal exportável em TXT/JSON.
- Guia SE/AE: corpo, esqueleto, física, BodySlide, combate, SPID, ordem de instalação e diagnóstico.
- Apêndice de origens LE para evitar instalar a edição errada, **fora da contagem de 75**.
- Ferramentas Python sem dependências externas para validar, gerar documentos, empacotar e inventariar arquivos locais.

## Limitações importantes

- **0 arquivos de mods incluídos; 0 downloads binários testados; 0 testes no Skyrim.**
- Não foi concluída a parte do pedido de baixar e reunir “quase todos os mods”. Este é o catálogo pesquisado, não uma alegação de coleção completa.
- O repositório é público. Uso pessoal não equivale a permissão para publicar uma cópia dos mods em uma release pública.
- As fontes estudadas incluem proibições de reupload, permissões condicionais e direitos não confirmados. Nenhum item recebeu autorização suficiente para ser espelhado aqui.
- Alguns registros usam somente índice de busca ou listagem do autor. Downloads podem exigir conta/assinatura ou estar indisponíveis.
- Algumas páginas externas podem mostrar conteúdo adulto. Não foram incorporadas imagens dos mods.
- Hashes desta release validam **os documentos produzidos pelo GHOST**, não os arquivos dos mods externos.

Os testes do repositório verificam os dados, a interface e o empacotamento documental; não certificam segurança nem compatibilidade dos mods. Veja `docs/RELATORIO.md` e `docs/PESQUISA.md` no ZIP.

**Créditos:** todos os mods e assets externos pertencem a seus respectivos autores/titulares. O catálogo referencia seus canais em vez de redistribuir os arquivos. Sem afiliação com Bethesda ou Pearl Abyss.
